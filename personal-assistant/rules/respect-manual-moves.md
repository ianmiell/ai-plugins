# Mail that left the inbox was moved by Ian on purpose

If a thread that was in the inbox when the assistant last looked (in an earlier triage list
this session, or one Ian was shown) is no longer in the inbox, assume Ian moved it himself,
deliberately: archived, trashed, labelled or marked as spam. The same goes for a thread Ian
starred or unstarred himself.

- Drop it from any pending recommendations. Don't re-propose actions for it, and don't count
  it as "still waiting" in the next list.
- Never undo it: don't move it back to the inbox, re-star or unstar it, or change its labels.
- Don't flag it as a house-rule violation. A thread Ian archived while starred, or a star he
  left on an archived thread, is his choice; leave it out of the "starred outside the inbox"
  offer in unstar-outside-inbox.md.
- Mention it at most once, in one line (e.g. "you've already dealt with 3 and 5"), so Ian
  knows the list is up to date.
- If a new message arrives in such a thread and brings it back to the inbox, triage the new
  message only. Don't revive recommendations from before Ian moved it.
- This applies to both mailboxes, and to Slack conversations Ian has clearly dealt with
  himself (replied to, reacted to, or marked done).
